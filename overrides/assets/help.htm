Luồng làm việc

  1. Designer đặt tên frame theo quy ước ROLE-MENU-MMTTPS — Tên / Tab / Popup / Trạng thái, cập nhật bảng NAVIGATION trên Figma.
  2. BA viết docs và ghi mã màn hình (vd ADM-HV-020310, dải CD-KH-070301–070305). Không cần dán link hay ảnh: mã tự thành link mở đúng prototype.
  3. Admin bấm Đồng bộ › Sync danh sách màn khi NAVIGATION thay đổi, và Kiểm tra UI thay đổi để biết frame nào vừa sửa.
  4. Người review so docs với prototype, admin bấm Đánh dấu đã đồng bộ.

Mã màn hình

  • Mã thường mở màn Light. Mã có đuôi -DK mở màn Dark tương ứng.
  • Bấm mã trong docs: khung Figma bên phải chuyển sang màn đó. Giữ Ctrl/⌘ khi bấm để mở thẳng trong Figma.
  • Mã gạch ngang: không có frame trên Figma (đã đổi tên hoặc xoá).
